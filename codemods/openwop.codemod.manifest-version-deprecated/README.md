# openwop.codemod.manifest-version-deprecated

RFC 0178 §A.1 / row `openwop.migration.C11.2`: renames the registry version manifest's advisory `deprecated` boolean to `versionDeprecated` so the JSON Schema `deprecated` annotation keyword is unambiguous. Refuses a non-boolean or a disagreeing pair. Negative control: a manifest without the field is unchanged. Idempotent. The manifest's detached signature must be regenerated by the registry (C.10); this transform changes bytes.
