IDRiskLikelihoodImpactScoreMitigationOwnerStatus
R1False sense of certification — a self-published bundle is read as "certified" when its host.commit + results are self-reported and unverified.MHHigh§B mandates a consumer RE-DERIVE profiles from the embedded discovery.document (don't trust claimedProfiles); spec language (G5) restricts authoritative bundles to independent-verifier generation; reproducibility (re-run suite vs commit) is the integrity story.Security ArchitectOpen
R2Bundle staleness — a published bundle ages out of sync with a changing host; readers act on a stale pass list.MMMedRequired generatedAt + host.commit make every bundle a dated point-in-time attestation; certificationBundleUrl SHOULD point at the latest; doc says bundles are snapshots, not live state.Spec ArchitectOpen
R3Scenario-ID drift across suite versions breaks results.passed diffability + the floor-scenario match in §B(2).MMMedG2/G3 audit ID stability before schema finalization; pin suite.version in every bundle so a verifier matches floor sets to the same suite.Conformance ArchitectOpen
R4Floor-set definition gap (G1) — without a machine-readable floor-scenario set per profile, §B(2) can't be verified, stalling Active.MMMedResolve G1 in the comment window; may land a small prerequisite (floor-set manifest) first.Spec ArchitectOpen
R5Vitest-reporter coupling — the generator parses vitest JSON; an upstream reporter change breaks --certify.LMLowParse the documented --reporter=json shape only, not internals; a single conformance assertion round-trips a sample so a break is caught in CI.Conformance ArchitectOpen
R6Scope creep into signing/provenance turns an additive format RFC into a security-infrastructure project, delaying the audit's ask.MMMedKeep v1 bundle unsigned-but-reproducible (Unresolved Q3 / G4); defer signing to a clearly-scoped follow-up that wraps this payload.Spec ArchitectOpen
