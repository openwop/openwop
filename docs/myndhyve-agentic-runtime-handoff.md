## Ground rules (all RFCs honor these)

- **Honest advertisement.** Advertise a capability only when you fully honor its contract. Partial/Tier-1 is fine and is what graduates `Draft → Active`.
- **Additive.** Every one of these is a new optional capability / event field / endpoint / version rung — nothing breaks your existing v1 conformance pass. `executionModel.version: 5` is a widening of the ladder; `version: 4` hosts stay valid.
- **Redaction-safe.** No credential/token/PII/secret crosses the wire, enters events, archives, debug bundles, or replay state. `media-asset-url-tenant-scoped` (0055), `memory-attribution-no-content` / `-tenant-scoped` (0057), and SR-1 carry-forward through distillation (0062) are hard MUSTs.
- **Replay-deterministic.** New event fields (`iteration`, `distillation`, `memory.written`) are recorded in the log and re-emitted verbatim on replay/`:fork` — never recomputed from a clock or regenerated.
- **Fail-closed + atomic.** Bound breaches terminate the run (0058); an un-meetable distillation budget writes no partial archive (0062).
- **Seams are conformance-only.** The `/v1/host/sample/*` endpoints return `404`/`403` in production unless env-gated; never expose them to real tenants.
