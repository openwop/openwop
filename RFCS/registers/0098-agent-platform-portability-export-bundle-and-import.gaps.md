## Register sweep — `Active → Accepted` 2026-06-14

Per `RFCS/README.md` §"register sweep gates promotion", every open row is closed, transferred, or carried forward before this flip:

- **G5/G7 (Accepted-gating) — RESOLVED.** Idempotency-key + the mandatory `no-secret-values` Accepted gate + which host implements export/import first: resolved by the **openwop-app reference host** (rev `00174-6m6`), which carries the **`portability.import:true` non-vacuous witness** — `export-bundle-portability` 6/6 vs suite 1.24.0, steward-curl-verified live that import-of-a-literal-credential → **422 with the secret redacted in the error** (the mandatory no-secret-values gate, SR-1) and refs-only export → 200. The **non-steward witness** (MyndHyve rev `workflow-runtime-00269-ljm`) advertises `portability` with the declared **honest `import:false` opt-out** and serves export refs-only; the suite fails-loud without `OPENWOP_OPTED_OUT_PROFILES=portability`, which is the honest-advertisement discipline working as intended.
- **G1/G2 (signing / import-as-proposal) — carried forward as named future extensions** (optional detached signature; staged-as-RFC-0096-proposal for executable kinds), Draft-acceptable, tracked here.
- **G3/G4/G6/G8/G9 (scope / re-bind contract / dependsOn graph / adapters-non-normative / migrate-tenant superset)** carried forward as non-blocking; the `secretsToRebind` refs-only contract + topological apply are pinned in the floor.

Risks R1–R8 are mitigated by the shipped protocol-tier `export-bundle-no-credential-material` invariant (the highest-severity R1), the mandatory `dryRun` plan, and re-ownership-to-caller-identity; none block Accepted.
