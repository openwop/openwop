# RFC 0253 — Risk register

| ID | Risk | Likelihood | Impact | Score | Mitigation | Owner | Target | Status |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| R1 | A host normalizes a manifest on install (fills defaults, reorders arrays, drops hatch properties), so an honest install fails byte-match. | M | M | Med | JCS removes key order only; §C excludes nothing, and the Implementation notes tell a host to keep the original bytes. A failure here is the invariant working, not a false negative. | Schema Architect | at `Active` | `accepted` — the strict comparison is the point of `proposal-no-resynthesis`. |
| R2 | A client draft names a pack in a namespace it does not own (`vendor.<org>.*`) and shadows a registry pack inside its tenant. | M | H | High | §E refuses a name the host installed from a registry (`read-only`); UQ 1 proposes refusing any name outside `private.*`. Shadowing is confined to the caller's tenant by §A. | Security Architect | 2026-11-30 (at `Active`) | `transferred:RFC 0253 Unresolved questions` — UQ 1, decided at `Draft → Active`. |
| R3 | An agent-pack draft carries a `runtime.entry` URL, and a naive host fetches it on install (SSRF). | L | H | Med | §D: a host MUST NOT dereference `runtime.entry` for a proposed pure-agent pack; the suite's fixture uses an unroutable entry. The rule is disclosed `unwitnessable`. | Security Architect | at `Active` | `mitigated` — by §D and the falsifiability disclosure. |
| R4 | A proposed agent's inline `systemPrompt` is attacker-authored (a client draft) and becomes live behavior. | M | H | High | Unchanged by this RFC: a draft is inert until an authorized apply (RFC 0096, `proposal-inert-until-applied`), and the reviewer approves the exact bytes (`artifactDigest`, RFC 0249 §C). This RFC makes both observable for agent packs (`0253.agent-draft-inert`, `0253.agent-readback-byte-match`). | Security Architect | 2026-11-30 (at `Active`) | `mitigated` — by the existing activation rules plus the new legs. |
| R5 | `getInstalledPack` becomes a cross-tenant existence oracle for pack names. | L | H | Med | §A: a foreign or absent pack answers the same `404`; `0253.cross-tenant-not-found` compares the two. | Security Architect | at `Active` | `mitigated` — by §A and the leg. |
| R6 | Agent packs that need typed handoffs or eval suites cannot use the read-back path, so a host keeps proposing them without `readback`. | M | L | Low | Disclosed in §D; the facet keeps saying which kinds have no read-back; UQ 5 asks for a files phase. | Spec Architect | at `Active` | `accepted` — phase 2 is manifest-only. |
