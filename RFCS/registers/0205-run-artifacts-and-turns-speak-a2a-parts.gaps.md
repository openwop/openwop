# RFC 0205 — Gap register

Open design gaps found while authoring RFC 0205: the A2A `Artifact`/`Part` shapes, the turn `parts`, and the `exportFormats` media types. Rows are keyed to the RFC. Each row has an owner and a resolution path.

| ID | Section | Question / Missing Input | Owner | Resolution Path | Blocks |
| --- | --- | --- | --- | --- | --- |
| G1 | §C.12 / §E | The v2 `artifactTypes` family is still homed in `spec/v1/artifact-type-packs.md`, so §C is written there and binds both majors. A full v2 home needs about 700 words: store/render/export/types, the binding, validate-before-emit, the schema `$id` namespace and bounded compilation. It is granted 200 words of cap. | Spec Architect | `transferred:spec/v2/declaration.json`. Home `artifactTypes` in a dedicated normative-home RFC once cheaper families have funded the cap (RFC 0190's self-funding order). | Nothing here. |
| G2 | Conformance | No host implements `getArtifact` end-to-end. `artifact-auth.test.ts`'s header says so, and no conformance fixture emits `artifact.created` with a readable id. `0205.artifact-a2a-shape` and `.artifact-id-matches-path` therefore stay `inapplicable` everywhere until a host ships both. | Conformance Architect | `externally-gated:artifact-producing-fixture`. Add a `conformance-artifact-emit` fixture (one node that produces a registered-type artifact) to `conformance/fixtures/` + `fixtures.md`, and implement the read on the v2 reference host. | `Accepted` on a host row. |
| G3 | §A.3 | `0205.artifact-url-part-scoped` needs a host that emits `url` Parts and a second-tenant credential. Any host that emits only `data`/`text`/`raw` Parts makes the row vacuously inapplicable, which is honest but witnesses nothing. | Security Architect | `externally-gated:host-emitting-url-parts` — Reuse the `OPENWOP_TEST_TENANT_B_API_KEY` harness from the content cross-tenant legs. Consider extending invariant `media-asset-url-tenant-scoped`'s `tests:` to name the new scenario, rather than minting an invariant. | Nothing. |
| G4 | §B.5 | A `system` turn has no A2A `Role`, so a turn with `role: system` and `parts` is A2A-*shaped* but not A2A-*projectable*. | Spec Architect | `transferred:rfc-0208`. The projection rule belongs to the A2A mapping registry (`spec/v2/interop-map.json` `a2a.fields`, homed by RFC 0208); the RFC's Unresolved question 2 lists the candidates. | Nothing. |
| G5 | Forward path | The later emission MUST needs a gating facet. `getArtifact` belongs to no family, and minting a facet here would be premature, because no host has asked to advertise it. | Spec Architect | `transferred:phase-4-content-must-rfc` — The Phase 4 content-MUST RFC chooses the facet: either a new `artifacts` family or a facet of `artifactTypes`. It files once this RFC is `Active` and flips only after this RFC is `Accepted` (arch-P4 §6.3). | The Phase 4 content MUST, not this RFC. |
| G6 | §B.8 | The v1 turn gains no `parts`, so a v1 → v2 fork of a v1 run carries no A2A-shaped turns. That is correct because nothing is synthesized, but a cross-major replay is still unrenderable. | Compatibility Architect | `transferred:spec/v1/migrations.json` — Record in the v1→v2 migration register that `content` is `never-upgraded` (arch-P4 §4 content row) and that no codemap row synthesizes `parts`. | Nothing. |
| G7 | §D | The schemas are transcribed from `a2a.proto` by hand. Nothing detects a future A2A minor that adds a `Part` or `Artifact` field. The closed v2 objects would then reject a field a peer legitimately sends. | Schema Architect | `transferred:conformance/fixtures/upstream/a2a-v1.0.1` — Add a pinned copy of the relevant `a2a.proto` messages to `conformance/fixtures/upstream/a2a-v1.0.1/`, with a server-free leg that diffs field names. Re-transcribe on each A2A minor as a v2.x additive change. | Nothing. |
| G8 | §C.9 | Media-type parameters (`text/csv; charset=utf-8`) are refused by the pattern. A format that exists only as a parameterized type cannot be named. | Schema Architect | `externally-gated:pack-needs-media-type-parameters` — Widen to RFC 6838 parameters only when a pack needs one. It is also a superset change. | Nothing. |
