| R1 | A host evaluates `If-None-Match: *` before deciding the caller may read the run, so `304` versus `404` discloses that a run exists. | L | H | Med | §A makes evaluation conditional on a `2xx` unconditional answer; §D 4 witnesses it on an absent run.
