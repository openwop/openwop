# RFC 0058 — Risk Register

Companion to [`RFCS/0058-run-execution-bounds.md`](../0058-run-execution-bounds.md). Likelihood × Impact (H/M/L). Critical/High require a named mitigation owner.

| ID | Risk | Likelihood | Impact | Score | Mitigation | Owner | Status |
|---|---|---|---|---|---|---|---|
| R1 | A strict consumer validating `cap.breached.kind` against the *old* frozen enum rejects the two new kinds (`run-duration`, `loop-iterations`). | L | M | Med | Payload is `additionalProperties: true` + kind is a string discriminator → generic handling tolerates unknown kinds. Precedent: RFC 0008 §K added `wasm-*` with no bump. Documented as Unresolved #3 / G3. | Compatibility Architect | Open |
| R2 | Hosts implement `runTimeoutMs` naively as a hard kill that drops the event log before persisting `cap.breached` + `run.failed`, leaving a run in a non-terminal state on restart. | M | H | High | Normative MUST: flush the `cap.breached` + `run.failed` events before terminating (G1). Conformance `run-timeout-fires.test.ts` asserts both events land. | Spec Architect | Open |
| R3 | Loop-iteration counting diverges across hosts (counts orchestrator turns differently), so a workflow with `maxLoopIterations: 20` terminates at different points on different hosts → non-portable. | M | H | High | Pin "one increment per orchestrator turn per `multi-agent-execution.md` §Execution loop"; conformance `run-loop-limit-fires.test.ts` asserts the (N+1)th-turn trip; depends on RFC 0061 landing the loop contract. | Conformance Architect | Open |
| R4 | `observed` (elapsedMs/iterationCount) regenerated from a live clock at replay/`:fork` time → replay divergence. | L | H | Med | Normative MUST in §C: record `observed` in the event, reuse on replay, never recompute (per `replay.md`). Mirrors existing `node-executions` recording. Conformance composes with RFC 0041 replay suite. | Security/Replay reviewer | Open |
| R5 | Adding two `limits` fields + two reserved keys to an already-dense surface increases the run-create validation surface; a host that clamps incorrectly could silently truncate a run the caller expected to complete. | L | M | Low | Clamp = `min(requested, ceiling)` with `400 validation_error` only for out-of-range values at create-time, never silent runtime truncation; `run-bounds-clamp.test.ts` asserts clamp behavior. | Schema Architect | Open |
| R6 | Cohort sequencing: RFC 0061 (`maxLoopIterations` enforcement) and RFC 0064 (`durationMs` determinism) depend on 0058; if 0058 stalls in review the cohort stalls. | M | M | Med | 0058 is the smallest, lowest-risk RFC (additive enum + 2 optional keys); prioritize its 7-day window first. | Cohort owner | Open |
