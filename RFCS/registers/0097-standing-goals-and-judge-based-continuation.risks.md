# RFC 0097 — Risk Register

Likelihood × Impact (H/M/L). Critical/High risks carry a named mitigation owner.

| ID | Risk | Likelihood | Impact | Score | Mitigation | Owner | Status |
|---|---|---|---|---|---|---|---|
| R1 | **Runaway continuation** — a never-satisfied goal re-engages work forever (cost/iterations unbounded), the unattended-agent nightmare. | M | H | **High** | §E(2) MUST: an `active` goal without RFC 0058 `bounds` is invalid when `requiresBounds` is advertised (default true); the host MUST stop and set `bound-exceeded` at any ceiling. Conformance scenario: never-satisfied goal halts exactly at `maxIterations`, no further runs. | Spec Architect | Open |
| R2 | **Judge cost blowup** — a verifier invocation per iteration silently multiplies spend; goals become expensive in a non-obvious way. | M | H | **High** | Account judge cost against `bounds`/RFC 0084 budget (G5); `budget.*` gates spend; document that each check is a metered run. | Compatibility Architect | Open |
| R3 | **Client-side completion spoofing** — a client sets `state: satisfied` directly, bypassing the judge and declaring victory falsely. | M | H | **High** | §E(1) MUST: completion is the judge's verdict; there is **no** `complete` write and `PATCH` to `state: satisfied` is rejected. Conformance scenario asserts the rejection. | Security Architect | Open |
| R4 | **Objective / verdict content leak** — `goal.evaluated`/`goal.closed` events leak the objective text or sensitive verdict reasoning. | L | M | **Med** | §E(5) SR-1 redaction-safe; events are content-free (`goalId`, `satisfied`, `confidence`, `runId`, counts only); invariant `goal-event-no-content-leak`. | Security Architect | Open |
| R5 | **Escalation deadlock** — a goal escalates (RFC 0044) but no human ever resolves it; continuation is halted and work silently stalls indefinitely. | M | M | **Med** | §E(3) sets `escalated` + halts (correct, fail-safe); a wall-clock bound still applies → eventual `bound-exceeded`; host SHOULD surface escalated goals in an operator view. | Spec Architect | Open |
| R6 | **Replay divergence** — a non-deterministic judge makes a replayed goal loop reach a different verdict/iteration count than the original. | M | M | **Med** | Explicit Unresolved-questions note (G6); gate determinism claims on RFC 0041; `goal.evaluated.runId` makes each verdict attributable for audit even if non-deterministic. | Conformance Architect | Open |
| R7 | **Boundary erosion vs RFC 0068** — implementers build a goal as "a commitment that repeats," collapsing the termination guarantee into a fire-arm and losing the judge loop. | M | M | **Med** | Normative boundary note (G8) + distinct capability (`agents.goals` vs `agents.commitments`); a goal *composes* a commitment, never *is* one. | Spec Architect | Mitigated-by-design |
