# RFC 0140 — Risk register

Filed retroactively (2026-08-08) as part of the `Accepted` register sweep. Scored Likelihood × Impact (H/M/L).

| ID | Risk | Likelihood | Impact | Score | Mitigation | Owner | Status |
|---|---|---|---|---|---|---|---|
| R1 | **`none` is read as permission to re-fire.** The enum's default reads like an opt-out, and an implementer who skims the capability table will conclude that not advertising means the guarantee does not apply — reintroducing exactly the MUST-relaxation this RFC was corrected to avoid. The RFC's own first draft made that mistake. | **H** | **H** | **Critical** | Said three times, in the places a reader actually lands: the schema `description` at the point of use, the §"Side-effect suppression in replay" capability table, and the sentence immediately under it ("A host MUST NOT read `none` as permission…"). §Summary's dated correction preserves the reasoning so it is not re-derived wrongly later. | Spec Architect | Open (mitigated by placement, not closable) |
| R2 | **The fail-closed witness is read as proving the happy path.** The scenario's positive evidence is `replay_source_missing` on an unrecorded node. That is unforgeable — but it does not observe whether a node *with* a recorded outcome re-fired and recorded identically. | **H** | M | **High** | Stated in the scenario docstring itself ("true of the HAPPY path"), and carried as gap G2. The reference host implements an effect counter that closes it; a strengthening leg lands when a second host has the seam. | Conformance Architect | Open (disclosed) |
| R3 | **The seam guard is skipped as "already covered".** A reader who sees the classifier working concludes requirement 5 is satisfied and advertises. That is the partial implementation requirement 5 forbids, and its failure mode is silent. | **H** | M | **High** | Borne out in practice, which is why requirement 5 is now explicit: the reference host's guard existed but covered **3 call sites against ~25 node-reachable outbound paths** until ADR 0533 widened it to the shared egress dispatcher. Requirement 5 makes (a)-only advertisement a MUST NOT, not a SHOULD. | Steward | **Closed** — requirement 5 landed; guard widened |
| R4 | **Classifier drift recurs.** openwop-app has already lost protection for 55 chain nodes once, when a node type was retargeted and pack `.mjs` nodes could not self-declare. Nothing in classification prevents a repeat. | **H** | M | **High** | This is the argument *for* requirement 5(b): the seam guard makes drift fail **closed** instead of fail open, converting a silent correctness loss into a visible `replay_source_missing`. Drift remains likely; its consequence is what changes. | Host owners | Mitigated by design, not eliminated |
| R5 | **Guarding the convenience wrapper instead of the chokepoint.** A host that guards its highest-level egress helper can leave lower-level paths (raw fetch, MCP tool invocation) open while believing it is covered. | M | **H** | **High** | Recorded concretely in §Implementation notes from ADR 0533's finding: guarding `guardedEgressFetch` alone left `safeFetch` and MCP open because six modules call the underlying fetch directly. Guard the shared dispatcher; add a source-scan tripwire test, since the guarantee rests on no call site bypassing it. | Host owners | Open (guidance, not enforceable by spec) |
| R6 | **A replay of a long workflow outlives the poll budget.** A `replay` fork re-executes pure nodes live, so a fixture's own delay is a floor on the fork's runtime — measured, not theorised: the first scenario draft used a 30s delay and timed out with the fork still `running`. | M | L | Low | The shipped fixture uses a short delay, with the reasoning inline so it is not "optimised" back up. Any host-side scenario copying this shape needs a budget strictly greater than the delay. | Conformance Architect | **Closed** — fixed at landing |
| R7 | **The three `replay.md` sites describing this guarantee drift apart again.** Caveat 1, §"Replay-from-event-log internals" item 4, and §"Side-effect suppression in replay" all speak to it. | M | L | Low | The new section is the single normative home; caveat 1 and item 4 now forward-reference it rather than restating the mechanism, so a future edit has one place to change. | Spec Architect | **Closed** — single source of truth |
| R8 | **A host advertises before implementing**, since the capability is a self-declaration with no gate but conformance. | M | M | Med | Truthful-advertisement is normative and `OPENWOP_REQUIRE_BEHAVIOR=true` fails a dishonest claim. Host-sample seams measure *cooperating* hosts and are not an adversarial control — stated rather than implied. | Conformance Architect | Open (bounded, not closed) |
