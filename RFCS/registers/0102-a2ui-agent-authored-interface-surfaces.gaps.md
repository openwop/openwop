# RFC 0102 — Gap Register

Working document (not normative). Per `RFCS/README.md` § "Registers", a status flip to
`Accepted` requires a **register sweep**: every open row must be closed, transferred to a
tracked surface, or carried forward as a named open gap in the RFC.
