# RFC 0105 — Risk Register

Working document (not normative). Likelihood × Impact, each H/M/L. Critical/High-scored risks
carry a named mitigation owner. Per `RFCS/README.md`, open rows gate the `Accepted` flip and
must be swept.

| ID | Risk | Likelihood | Impact | Score | Mitigation | Owner | Status |
|----|------|------------|--------|-------|------------|-------|--------|
| R1 | **`Active` locks the shape before any reference host has exercised it.** A field/method name proves wrong once openwop-app implements, forcing a post-`Active` change. | M | M | **Med** | The surface is additive + capability-gated, so a post-`Active` refinement stays cheap (new optional field / additive amendment). The request/response shape is a verbatim parallel of the already-shipped `ctx.callImageGenerator` (`host-capabilities.md:81`), which two hosts have exercised — the names are not novel. Any change flagged as a blocking cross-host item before it lands. | Author | Open — keep openwop-app + the second witness aligned on the verbatim names (`callSpeechSynthesizer`, `text`, `voiceId`, `audio.{url,base64,mimeType}`) through implementation. |
| R2 | **A `url`-served audio asset becomes an SSRF / unguarded-fetch vector.** A host fetches/serves the provider's audio URL without the SSRF guard, or lets a pack-supplied URL reach internal infra. | L | H | **Med** | §D MUST: a `url`-referenced asset is served/fetched through the host's SSRF-guarded path (RFC 0076 `ctx.http.safeFetch`); audio bytes inherit the RFC 0091 §C untrusted-media boundary. Reuses an existing protocol-tier guard — no new invariant invented; the Accepted conformance bundle asserts the boundary. | Security Architect | Open — confirm the SSRF-guarded serve path in the host impl; assert in the Accepted conformance leg. |
| R3 | **Round-trip prompt injection.** `text` is model/user-derived and MAY carry injected instructions; if the synthesized audio is later transcribed / re-perceived (RFC 0091 input), the instructions re-enter the run as if trusted. | M | M | **Med** | §D MUST NOT: `text` MUST NOT be treated as trusted on a round-trip; synthesized bytes carry the UNTRUSTED marker like any generated media. Mitigation is reuse of the RFC 0091/`threat-model-prompt-injection.md` §D discipline, not a new mechanism. | Security Architect | Open — land the §D note in `threat-model-prompt-injection.md` at `Accepted`. |
| R4 | **`voiceId` encodes secret material.** A host maps `voiceId` to a provider voice via an opaque string that smuggles a credential / tenant secret, which then appears in event logs or replay payloads. | L | M | **Low** | §D MUST NOT: `voiceId` MUST NOT encode secret material; it is an opaque host-resolved handle. BYOK/SR-1 unaffected (audio bytes are not credentials). Standard secret-leakage discipline (`threat-model-secret-leakage.md`). | Security Architect | Open — host review; covered by existing redaction posture. |
| R5 | **Capability dishonesty.** A host advertises `aiProviders.speechSynthesis: supported` without a working TTS route, so `callSpeechSynthesizer` calls fail at runtime despite the advertisement. | M | M | **Med** | The gated `speech-synthesis-roundtrip.test.ts` is non-vacuous under `OPENWOP_REQUIRE_BEHAVIOR=true` — an advertising host that can't synthesize fails the suite; INTEROP-MATRIX honesty rule applies. | Compatibility Architect | Open — wire the non-vacuous round-trip + MATRIX honesty before `Accepted`. |
| R6 | **Unadvertised call silently no-ops** instead of rejecting, so a pack on a non-TTS host gets undefined behavior. | L | M | **Low** | §C MUST: an unadvertised `callSpeechSynthesizer` MUST be rejected with `speech_synthesis_unsupported` (never no-op), paralleling RFC 0091's `unsupported_modality`. Register-time refusal via `peerDependencies`/`requiredHostCapabilities` is the primary path; runtime check is defense-in-depth. The gated-by-absence `speech-synthesis-unadvertised.test.ts` asserts it. | Conformance Architect | Open — wire the unadvertised-reject leg at `Accepted`. |
| R7 | **Third-party hosts adopt the additive surface but pin an old conformance suite → INTEROP-MATRIX drift** (standard additive-surface adoption lag). | M | L | **Low** | Gate new scenarios on `aiProviders.speechSynthesis: supported` membership (soft-skip otherwise, matching the additive-surface precedent); remind in §Conformance. | Conformance Architect | Open — standard mitigation. |

**Register sweep — `Active` (2026-06-20).** No High/Critical rows. The Medium rows (R1, R2, R3, R5)
are mitigated by **reuse of existing protocol-tier guards** (RFC 0076 SSRF, RFC 0091 untrusted-media,
the non-vacuous gated conformance legs) rather than new mechanisms; each is wired into the `Accepted`
conformance + spec-doc bundle. No open row blocks the `Draft → Active` waiver.
