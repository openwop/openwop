# RFC 0192 — Gap register

Open design gaps discovered while authoring RFC 0192 (the v2 facet advertisement semantic). Keyed to the RFC; each row has an owner and a resolution path.

| ID | Section | Question / Missing Input | Owner | Resolution Path | Blocks |
| --- | --- | --- | --- | --- | --- |
| G1 | §A | A host has no way to advertise a facet NEGATIVELY — "I know about this and do not offer it". Presence-semantics makes omission the only spelling, which cannot distinguish *unsupported* from *not yet considered*. MyndHyve expresses exactly this today as `extensions.myndhyve.runs.pauseResume.supported = false`, fleeing to the vendor namespace because the core root cannot say it. That is a production host routing around a missing surface, which is evidence the gap is real rather than theoretical. | Spec Architect | `carried:openwop.gap.0192.1` — decide whether a negative advertisement is worth a wire surface. It is not free: it re-introduces a flag-shaped field, which is what RFC 0169 §A.2 retired, so the answer may legitimately be "no, and omission is the spelling". Revisit if a second host routes around it the same way. | Nothing. Omission is unambiguous for every consumer that only asks "is this offered". |
| G2 | §B | The rewrite table is keyed on the exact v1 sentence, so a reworded v1 seed silently stops matching and the ghost returns — caught by §C's gate, but as a new failure rather than as a diff on the table. | Conformance Architect | `carried:openwop.gap.0192.2` — acceptable as built: §C fails the generator, so the ghost cannot reach a published artifact. The residual cost is that the author sees "add a rewrite" rather than "your seed changed". Worth a stricter form (assert every table key still matches something) if the v1 seed ever becomes mutable again; it is frozen today. | Nothing; §C is the backstop. |
| G3 | §A | Eight core families carry zero facets, so the facet rule is vacuous for them, and `facetsUncovered` gives them no backstop either (RFC 0190 §B). Nothing in the corpus distinguishes "this family genuinely has no sub-capabilities" from "its facets were never modelled". | Spec Architect | `carried:openwop.gap.0192.3` — resolve alongside the remaining normative-home work, where each of the eight gets read anyway. A family with no facets and no v2 prose is the shape most likely to be under-specified rather than simple. | Nothing today. |
