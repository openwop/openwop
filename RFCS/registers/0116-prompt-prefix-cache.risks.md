# RFC 0116 — Risk Register

Score = Likelihood × Impact (H/M/L). This is the highest-risk RFC in the token-economy set; two risks are High and block `Active`.

| ID  | Risk                                                                                                          | Likelihood | Impact | Score | Mitigation                                                                                          | Owner               | Status |
| --- | ----------------------------------------------------------------------------------------------------------- | ---------- | ------ | ----- | -------------------------------------------------------------------------------------------------- | ------------------- | ------ |
| R1  | Naïve host shares a provider cache entry across tenants that supplied the same `cachePrefixId` → **cross-tenant context leakage** | M | H | High | **RESOLVED (architect 2026-06-26):** MANDATED `(tenant, cachePrefixId)` key + new protocol-tier invariant `prompt-prefix-cache-cross-tenant-isolation` + cross-tenant probe (B's first use of A's prefix → `cacheReadTokens==0`) | Security Architect  | Mitigated |
| R2  | Provider cache state subtly changes model output → cache hit ≠ cold path → **replay (RFC 0041) diverges** | M | H | High | **RESOLVED:** `cachePrefixId` is cost-hint-only MUST — recorded envelope + `provider.usage` input/output tokens identical hit-vs-miss; cache metrics cost-only + replay-non-asserted; conformance asserts outcome-invariance. (R5/Q5: if a provider violates this, host MUST NOT advertise it.) | Security/Spec       | Mitigated |
| R3  | `cachePrefixId` accidentally derived from BYOK plaintext → key material in logs/metrics                       | L          | H      | Med   | Normative MUST NOT derive from secrets; BYOK-boundary rejection; redaction scenario                 | Security Architect  | Open   |
| R4 | No observable conformance signal → only host-attested benchmark | M | M | Low | **RESOLVED:** `provider.usage.cacheReadTokens`/`cacheWriteTokens` (cost-only, replay-non-asserted) give a real wire witness for cache hit + cross-tenant non-share — no benchmark-graduation needed | Conformance Architect | `closed` Resolved |
| R5  | Effort sunk into a provider-specific feature that never becomes portable → spec carries a vendor-shaped field | M          | M      | Med   | Do-nothing is a live alternative; comment window may conclude this stays host-internal              | Spec Architect      | Open   |
