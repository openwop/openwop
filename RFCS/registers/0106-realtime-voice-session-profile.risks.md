# RFC 0106 — Risk Register

Likelihood × Impact (H/M/L). Critical/High risks carry a named mitigation owner and a target resolution milestone.

**Deep-dive update (2026-06-23):** R2 and R3 downgraded — the live-ingress threat pass produced §F (four conformance-testable invariants), and the return-primitive / handle decisions are now grounded in SDK code + cross-protocol precedent rather than survey inference. R2/R3 mitigations are in-RFC; residual risk is the external-audit coordination (R2) and the author-confirmation gate (new R9).
