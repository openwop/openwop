# RFC 0209 — Gap register

This register lists the open design gaps found while writing RFC 0209, which makes the v2 `ui.a2ui-surface` schema version 2 speak A2UI v0.9. Each row is keyed to the RFC and has an owner and a resolution path.

| ID | Section | Question / Missing Input | Owner | Resolution Path | Blocks |
| --- | --- | --- | --- | --- | --- |
| G1 | Conformance | Three things are missing before the four seam-gated rows (`version-selects-branch`, `fold-guarded`, `legacy-readable`, `taint-sticky`) can be witnessed. There is no v2 emit-surface seam: v1's lives in `host-sample-test-seams.md` and is major-1, and `api/seams-v2.yaml` has no A2UI seam. No v2 host renders or emits A2UI. And no committed v2 bundle carries the kind. | Conformance Architect | `externally-gated:v2-a2ui-emit-seam`. Two steps: (1) add a v2 seam operation to `api/seams-v2.yaml` that records a caller-supplied `ui.a2ui-surface` envelope through the engine's normal admission path, carrying a `contentTrust` control; (2) have one host implement it. openwop-app has the v1 seam and renderer; the v2 reference host has neither. | `Accepted` on host rows. |
| G2 | §B.6 | The profile excludes `Icon`, `List` (templated children), `Tabs`, `Modal`, `Slider`, and every `FunctionCall` except `required`. Some real surfaces will want these. | Spec Architect | `externally-gated:surface-author-demand` — Each addition must stay a subset of upstream and must keep every `a2ui-*` invariant. Admitting a component is a widening, so it goes in the schema-version-2 branch and needs no new version. | Nothing. |
| G3 | §C.9 | "Exactly one `root` before render" and "no action before finalization" are render-side rules that the server-oriented suite cannot see. | Conformance Architect | `transferred:openwop-app:frontend/react/src/chat/a2ui/__tests__/a2ui-render-invariants.test.tsx`. Extend the reference-app client probe that already witnesses `a2ui-surface-no-code-exec` and `-no-network-egress` (tier `reference-impl`). | `Accepted` on the render row. |
| G4 | §D.14 | `ui` and `media` are still not listed in `spec/v2/declaration.json` `reservedOrgs`, so a vendor could apply to register either one and collide with the core kind families. | Spec Architect | `transferred:spec/v2/declaration.json` — Add both to `reservedOrgs` in a follow-up. Coordinate with Phase 1 PR P1-F, which is reconciling the reserved-orgs prose in `spec/v2/core/capabilities.md` against the declaration, so the two edits do not conflict. The only reason this was left out of 0209 is to avoid that collision. | Nothing today, because no such application exists. |
| G5 | §D.15 | The deprecation row can say only `removeIn: "3.0"` until RFC 0197 adds a `v2-minor` removal trigger. `check-removal-dates.mjs` compares majors only (arch-P4 finding 5). | Compatibility Architect | `transferred:rfc-0197`. Once 0197 is `Accepted`, re-point the row to `removalTrigger: "v2-minor"` and run the bundle-scan and manifest-census legs 0197 adds. Otherwise the frame stays deprecated until 3.0, which is harmless because no v2 host advertises it. | Nothing. |
| G6 | §C.10 | The v1 `field.select` resume value is a string. The v0.9 `ChoicePicker` binds to a string array. So a workflow migrated through the informative codemap receives `["eu"]` where it received `"eu"`. | Spec Architect | `closed` — Document this in the migration table (done). A workflow reading the value must accept both. Adding a `ChoicePicker` single-value binding is not possible without leaving upstream. | Nothing; the codemap is informative. |
| G7 | §B.4 | The profile is pinned to the bytes a2ui.org served on 2026-09-22, which include the 0.9.1 patch and differ from the repository's `v0.9` git tag. If a2ui.org changes those files in place, the vendored copies drift from what upstream serves. | Schema Architect | `transferred:conformance/fixtures/upstream/a2ui-v0.9` — Store the SHA-256 pins in the fixture README. Add a weekly (non-PR) check that fetches the three URLs and reports any drift. It must never be a PR gate, because the network is unreliable. | Nothing. |
| G8 | Unresolved Q3 | A2A peers exchanging A2UI (`mediaType: "application/a2ui+json"` data Parts, the A2UI A2A extension URI) are outside this RFC. | Spec Architect | `transferred:rfc-0208`. This belongs to the A2A mapping registry (`spec/v2/interop-map.json`), which RFC 0208 homes. | Nothing. |
