# RFC 0139 — Gap register

| ID | Section | Question / Missing Input | Owner | Resolution Path | Blocks |
|---|---|---|---|---|---|
| G1 | Proposal | **Projection equality needs a precise removal rule.** "Equal after removing the extension properties" must be recursive for a host that echoes its input manifest inside the projection. Whether that is normative prose or left to the suite comparator is open. | Schema Architect | `carried:openwop.gap.0139.1` The suite comparator is the reference either way; promote to prose only if a second host implements the seam and diverges. | Nothing today |
| G2 | Conformance | **One kind, one host.** The differential lands on the artifact-type seam because it is the only one with a real host behind it. Whether `card` / `connection` / `form-content` need their own leg, or whether one kind witnesses a corpus-wide rule, is undecided. | Conformance Architect | `carried:openwop.gap.0139.2` Decided by whether a second host wires a second seam. Deliberately not pre-built. | An `Accepted` gate claiming corpus-wide host-side coverage |
| G3 | Proposal | **The differential covers install-time sinks only.** A host that stores the extension and interprets it at a later moment the seam never reaches passes leg 3. No finite suite closes this. | Security Architect | `carried:openwop.gap.0139.3` Stated as a limit in §Conformance rather than papered over. Closing it would need host-side taint tracking, which is not conformance surface. | Nothing; bounds what a green run may be said to prove |
| G4 | Non-scope | **G8 (RFC 0138) cannot ride on this seam.** The reference host's seam emits no `artifact.created` — it emits only from `feature.documents.nodes` inside a real run; `persistRunArtifact` explicitly does not.
