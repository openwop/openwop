# RFC 0140 — Risk register

Scored Likelihood × Impact (H/M/L).

| ID | Risk | Likelihood | Impact | Score | Mitigation | Owner | Status |
|---|---|---|---|---|---|---|---|
| R1 | **`none` is read as permission to re-fire.** The enum's default value reads like an opt-out, and a host implementer who skims §A will conclude that not advertising means the guarantee does not apply — reintroducing exactly the relaxation this RFC was rewritten to avoid. The first draft of this RFC made that mistake in its own schema description. | **H** | **H** | **Critical** | The schema `description` says it in capitals at the point of use ("This is NOT permission to re-fire"), §B.0 states the requirement unconditionally *before* the capability is mentioned, and §Compatibility records the rejected alternative with its `COMPATIBILITY.md` §2.2 citation so the reasoning survives. Three places a reader might look. | Spec Architect | Open (mitigated by placement, not closable) |
| R2 | **A green scenario is read as proving whole-run suppression.** The counter observes the effects the host routes through its counted seam. A leak through an uncounted path is invisible to the suite *and* to the counter, so leg 3 can be green on a host that still re-fires somewhere. | **H** | **H** | **Critical** | `coverage.md` carries an explicit "what this does NOT discriminate" paragraph, and the acceptance criteria require the host to report which paths are counted rather than a bare pass. Same disclosure posture as RFC 0139 R1. | Conformance Architect | Open (bounded by disclosure) |
| R3 | **Restoring the status-line coverage claim outruns the implementation.** §F puts the claim back at `Active`, before any host has demonstrated §B.4(b). If the RFC then stalls at `Active`, the corpus is left claiming coverage of a guarantee no host provides — the same class of defect this RFC was written to fix, just relocated. | M | **H** | **High** | Gap G7 records the reasoning (the status line describes the document, not the hosts). If the RFC stalls, the mitigation is a `KNOWN-LIMITS` row, not a silent claim. | Steward | Open until `Accepted` |
| R4 | **The seam guard is skipped as "already covered".** A reader who sees ADR 0341's classifier working will reasonably conclude §B.4 is satisfied and advertise. That is precisely the partial implementation §B.4 forbids, and its failure mode is silent. | **H** | M | **High** | §B.4 makes (a)-only advertisement a MUST NOT rather than a SHOULD, the RFC's Implementation notes are relabelled **target design** with the gap called out inline, and G1 blocks the `Accepted` flip on the guard existing. | Steward | Open until G1 closes |
| R5 | **Classifier drift recurs.** openwop-app has already lost protection for 55 chain nodes once, when a typeId was retargeted and pack `.mjs` nodes could not self-declare. Nothing in the classifier design prevents a repeat. | **H** | M | **High** | This is the argument *for* §B.4(b): the seam guard makes drift fail closed instead of fail open. It converts a silent correctness loss into a visible `replay_source_missing`. Drift remains likely; its consequence is what changes. | Host owners | Mitigated by design, not eliminated |
| R6 | **Declaring the `replay` block reds a host on a `modes` value.** The item-level `enum: ["replay","branch"]` is the only newly-constraining assertion in §A; a host advertising a third mode string validates today and would not after. | L | M | Low | Survey at `Active → Accepted` (gap G3); the enum drops to a bare string if any host is affected. The block is otherwise open and all-optional. | Schema Architect | Open until surveyed |
| R7 | **A host games the counter** by returning a constant, or by counting only the classified path it knows the suite probes. | M | M | Med | Leg 4 (`replay_source_missing` with no new effect) constrains the counter to be a function of real execution, and leg 1 requires it to have counted the original run. Not airtight: host-sample seams measure cooperating hosts and are not an adversarial control. Stated rather than implied — same limit as RFC 0139 R3. | Conformance Architect | Open (bounded, not closed) |
| R8 | **The three `replay.md` sites drift apart again.** Caveat 1, internals item 4, and the new §B all describe the same guarantee; §F reconciles them once, but nothing keeps them reconciled. | M | L | Low | §B is made the single normative home and the other two forward-reference it rather than restating the mechanism, so a future edit has one place to change. | Spec Architect | **Closed** — single source of truth |
