# RFC 0108 — Risk register

Likelihood × Impact (H/M/L). Critical/High risks carry a named mitigation owner.

| ID | Risk | Likelihood | Impact | Score | Mitigation | Owner | Status |
|---|---|---|---|---|---|---|---|
| R1 | A host serialises the configured endpoint base-URL into the capabilities document, a `run.*` event, or an error envelope (the §D leak) — disclosing internal network topology / enabling SSRF recon. | M | M | Med | The `self-hosted-endpoint-no-disclosure` invariant (§D) + the §E shape scenario (no URL-shaped `selfHosted` id) + the honesty scenario's payload scan; reuse the RFC 0046 redaction harness. Call out the opaque-id convention (G7) in spec prose. | Security Architect | Open |
| R2 | A host advertises `selfHosted: ["ollama"]` with **no** endpoint actually configured (dishonest claim) — a client routes to a dead provider and the advertisement becomes meaningless (the exact failure the surface exists to prevent). | M | H | High | §A.2 truthful-advertisement MUST + `OPENWOP_REQUIRE_BEHAVIOR=true` enforcement + the `aiproviders-selfhosted-honesty.test.ts` behavioral gate (distinguishes a real transport error from `capability_not_provided`). | Conformance Architect | Open |
| R3 | A client infers vendor capabilities (e.g. vision, function-calling) from a `selfHosted` id and sends an unsupported request → silent degraded output or a runtime error mid-run. | M | M | Med | §B capability-non-inference MUST: capabilities come ONLY from RFC 0031 `modelCapabilities.advertised[]` + RFC 0091 modalities; the host refuses unadvertised modalities with `capability_not_provided` (RFC 0031 §B gate). Default text-only. | Spec Architect | Open |
| R4 | Hosts adopt the additive field but stay on an older conformance suite → INTEROP-MATRIX drift (some hosts advertise `selfHosted`, the matrix doesn't reflect who honors §A.2/§D). | M | L | Low | Gate the scenarios on the capability flag (soft-skip when absent); add the INTEROP-MATRIX column in the same PR; remind in §Conformance. | Compatibility Architect | Open |
