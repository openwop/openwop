|---|---|---|---|---|---|
| G1 | Proposal §B.9 | SHOULD vs MUST for `apiHosts` when a provider is consumed by an RFC 0045 action / `reach: openapi`. | G5 | Conformance | The host-behavioral egress-allow-list scenario needs a reference host that pins credential egress to `apiHosts` (the in-memory/sqlite example hosts may not implement connector egress). | Conformance Architect | Confirm which reference host implements brokered connector egress; gate the behavioral scenario on it; the manifest-validity scenario is server-free and host-independent. | The behavioral conformance gate. |
