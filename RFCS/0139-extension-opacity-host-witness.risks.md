# RFC 0139 — Risk register

Scored Likelihood × Impact (H/M/L).

| ID | Risk | Likelihood | Impact | Score | Mitigation | Owner | Status |
|---|---|---|---|---|---|---|---|
| R1 | **The differential is read as proving total opacity.** A green leg 3 gets cited as "MUST-ignore is verified", when it covers install-time sinks only. This RFC would then have replaced an unverified rule with a *falsely* verified one — worse, because nobody looks again. | **H** | **H** | **Critical** | §Conformance carries an explicit "What this does NOT discriminate" section, and the acceptance criteria require the host to report **which assertions do not discriminate** rather than a pass count. The limit is stated in the RFC, the coverage doc, and the scenario docstring — three places a reader might look. | Conformance Architect | Open (mitigated by disclosure, not closable) |
| R2 | **The G14 flip breaks hosts that were green.** Any host advertising a declarative capability with no seam goes red on upgrade. | **H** | M | **High** | Intended behavior, not a defect — those hosts were always non-conformant and the suite simply failed to check. Classified as a suite-version requirement per `COMPATIBILITY.md` §2.3, so it arrives on suite upgrade rather than as a protocol change. `OPENWOP_OPTED_OUT_PROFILES` gives an honest exit. Blast radius unmeasured — see gap G6. | Compatibility Architect | Accepted, deliberate |
| R3 | **A host games the differential by returning a constant projection.** A seam that returns `{}` regardless of input satisfies leg 3 trivially. | M | H | **High** | Leg 5 (host still rejects a misspelled canonical field) and the baseline install legs constrain the projection to be a function of *something*. Not airtight: a host determined to fake a seam can fake a seam. The honest framing is that host-sample seams measure cooperating hosts; they are not an adversarial control. Stated here rather than implied. | Conformance Architect | Open (bounded, not closed) |
| R4 | **Only one kind and one host witness a corpus-wide rule.** The artifact-type seam is the only one with a real implementation, so a rule stated for all pack kinds is evidenced by one. | **H** | M | **High** | Scope is honest about this (gap G2): the leg is not duplicated speculatively across kinds with no host behind them. A speculative leg on an unimplemented kind would soft-skip everywhere and add coverage theatre. Revisit when a second host wires a second seam. | Conformance Architect | Open, deliberate |
| R5 | **G8 gets folded in during implementation** because the seam is right there, producing a leg that reports green without witnessing `artifact.created`. | M | H | **High** | The reference host surfaced the constraint **before being asked** and it is recorded in §"G8 is NOT in scope" with the host's own words plus the reason (`persistRunArtifact` does not emit; only `feature.documents.nodes` does). Anyone attempting the fold hits the explanation first. | Steward | **Closed** — documented pre-emptively |
| R6 | **Recursive extension-stripping in the comparator is subtly wrong**, causing leg 3 to pass on a host that does differ, or fail on one that does not. | M | M | Med | The comparator is suite code with its own sabotage check: inject a difference outside the extension keys and confirm leg 3 reds. Non-vacuity verified the same way RFC 0138's legs were. | Conformance Architect | Open until implemented |
| R7 | **Sequencing error.** Flipping G14 before the differential exists gives hosts a failure with no diagnostic; adding the differential first makes it skip on exactly the hosts it targets. | M | L | Low | §Implementation notes requires both to land together. | Steward | **Closed** — sequenced |
