## Register sweep (`Active → Accepted`, 2026-06-28)

Per `RFCS/README.md` §48 a flip to `Accepted` requires every register row closed, transferred, or carried forward as a named gap. Disposition:

| Gap | Disposition |
| --- | --- |
| **G1** `onChildFailure` default | **Closed at `Active`** — default `'collect'` (UQ1 resolved in-RFC; documented divergence from single-child `fail-parent`). |
| **G2** `first` vs `race` | **Closed at `Active`** — kept as two distinct enum values (UQ2); `joinModes` retains `race`. |
| **G3** capabilities placement | **Closed at normative-surface** — `fanOutPolicies` / `joinModes` / `maxFanOut` landed under the existing `dispatch` object in `capabilities.md`; `onChildFailureModes` added as the orthogonal second axis via openwop#789. |
| **G4** event TYPE names | **Closed** — `core.dispatch.fanOut` / `core.dispatch.join` registered in `run-event-payloads.schema.json` `$defs` + `api/asyncapi.yaml` (no namespace collision; `asyncapi validate` clean). |
| **G5** `maxFanOut` default | **Closed at normative-surface** — `maxFanOut` is a host-advertised ceiling (no protocol-mandated default); both witnesses advertise `16`. |
| **G6** `mergeOrder` under RFC 0063 attestation | **Resolved** by the normative terminal-fold-time clause (§G + §UQ4 resolution): `mergeOrder` is recorded from the parent host's single clock at **terminal-fold time**, persisted on the `core.dispatch.join` event at first execution, and **re-read (never recomputed) on replay** — so an attestation/approval-gated child folds at its post-approval terminal and its position stays stable regardless of the human's wall-clock decision time. **Carried forward (named, non-blocking):** an attestation-specific worked example is a documentation nicety deferred to a follow-up clarification; the wire guarantee is already normative. |
| **G7** dual non-steward host witness | **Closed** — see `INTEROP-MATRIX.md` §"Parallel sub-workflow fan-out and join (RFC 0118)". **Discovery/advertisement leg: dual-witness, steward-curl-verified 2026-06-28** (openwop-app prod + MyndHyve tier-2 sibling seam rev `00513-qib`; honest `joinModes` / `onChildFailureModes` subset divergence). **Behavioral leg: single-witness host-self-reported** (MyndHyve `dispatch-fanout-parallel` 10/10 non-vacuous, suite 1.45.0; openwop-app keeps its prod seam dark by deliberate posture). A steward-run authenticated `--base-url` behavioral cross-check is **deferred** (host API keys not exchanged). Per `GOVERNANCE.md` §"Acceptance evidence tiers" this is a tier-2 (steward-affiliated) + reference-host graduation, recorded as such — **not** independent-org dual-witness. |
| **G8** `iterationCap` interaction | **Closed at `Active`** — each parallel child counts one against `iterationCap` (UQ5). |
| **G9** conditional channel skip | **Closed at `Active`** — gating stays upstream in the `OrchestratorDecision` `nextWorkerIds` selection; no per-child predicate field added. |
